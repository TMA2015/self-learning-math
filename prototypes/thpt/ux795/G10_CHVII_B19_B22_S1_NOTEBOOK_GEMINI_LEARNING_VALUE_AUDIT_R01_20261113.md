### Important findings from actual scanned S1 pages

- **B19 printed p30–31 / PDF p31–32:** The SGK starts the chapter with a real CAD/map setting and lists the link between a linear function's graph and a line. It starts B19 by asking what the set of points M with \(\overrightarrow{AM}\perp\vec n\) looks like, showing normal/vector diagrams **before** introducing \(a(x-x_0)+b(y-y_0)=0\). The strongest teaching mechanism is **constructing the line from geometry**, not memorizing the equation.
- **B20 printed p36 / PDF p37:** First activity uses a specific pair of lines, **solve a 2×2 system → find common point → infer cut/parallel/coincident**; only then the general coefficient model. The general rule should feel motivated, not appear as a classification checklist.
- **B21 printed p43 / PDF p44:** Circle is defined through the **set of points at fixed distance from a center**, paired immediately with labeled coordinate diagram and boxed condition, then a worked example. A *coverage disk* is not the same as its *circle boundary*.

This is a better candidate for learner understanding than a generic planet/cooling-tower name drop. Recreate only an **original** math-correct diagram/interaction after AUTHORING review; never copy book images into public repo.
